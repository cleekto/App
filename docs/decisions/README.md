# Решения (ADR)

Один файл — одно решение. Внутри: контекст, рассмотренные варианты, выбор, последствия, дата.
Решение записывается в той же сессии, в которой принято, а не «потом».

## Что читать в первую очередь

`ADR-0006` — если предстоит трогать дедупликацию. Там объяснено, почему нельзя заменить компанию на команду везде.

`ADR-0004` и `ADR-0005` — если предстоит трогать публикацию. Первый про инженерную сторону, второй про решение владельца.

## Правило нумерации

Номера не переиспользуются. Отменённое решение остаётся файлом со статусом «отменено» и ссылкой на то, что пришло ему на смену. Удалённый ADR — это потерянный ответ на вопрос «почему так, а не иначе», который через полгода придётся выводить заново.

Этот файл — описание каталога, а не ADR. При чтении последних записей его пропускать.
