## Фикстуры — в git НЕ входят

`docs/fixtures/**` в `.gitignore`. Там сохранённые страницы обеих площадок:
14 страниц объявлений, страница выдачи ss.ge, структура формы myhome.

**Почему не отдаются:** настоящие телефоны и имена собственников, в одной
из страниц — JWT с почтой владельца. Чужие персональные данные, правило 10.

Тесты, которые их читают, помечены `it.skipIf(!hasFixtures)` и на машине
без фикстур пропускаются, не падая. Это осознанное решение: CI зелёный
без фикстур, а полнота проверки — на машине владельца.
